## Para ativar cada fotografia

1. Obter arquivo WebP válido com autorização de uso comercial, e registrar fonte e licença.
2. Salvar o arquivo em `public/images/offers/<nome>.webp` no repositório.
3. Adicionar o caminho exato à lista `verifiedOfferImages` em `src/routes/index.tsx`.
4. Executar build, conferir conteúdo WebP real, abrir o preview desktop e mobile e validar HTTP 200 no Network para cada arquivo.
5. Para Big Mac, Whopper e Subway, usar somente imagens oficiais dos produtos correspondentes com autorização adequada.

Não foram executados build, browser/preview, inspeção HTTP 200 ou teste visual dos 16 cards nesta execução; o ambiente local não tem acesso à rede GitHub.
